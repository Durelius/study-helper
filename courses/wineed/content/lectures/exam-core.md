| 1. Wine label | Answer questions about a label | 5 | Intro (label section), France and Italy legislation |

| 3. French wine | Match region ↔ grape | 5 | France deck |
| 4. Italian wine | Match designation ↔ region | 5 | Italy deck |

Part 2 is worth double, and true/false rewards exact recall: the false statements on this
kind of paper are true ones with **one fact swapped for its neighbour** — malic for tartaric,
nearest-the-seed for under-the-skin, ortho-nasal for retro-nasal. Learn the pairs.

## 1. Reading a label

The seven main details: **producer logo**, **designation**, **vintage** (harvest year),
**bottling agency/producer**, **alcohol (% vol)**, **volume**, **bottling number**. A producer
may add a **commercial (fantasy) name**, and in Italy a **vineyard name** after the
designation — in *Barolo Bussia*, Barolo is the DOCG and Bussia the vineyard.

| Term | Means | Don't confuse with |
|---|---|---|
| **Riserva / Reserve** | longer maturation in barrel | Superiore |
| **Superiore** | ≥ 0.5% more alcohol than the designation's minimum | Riserva |
| **Classico** | the historic production zone (Chianti Classico) | Riserva |
| **Millésime** | > 85% of the cuvée from one good year | Brut |
| **Blanc de Blancs / de Noirs** | Chardonnay only / Pinot Noir only | |
| **Premier Grand Cru Classé** | a ranking of the *producer* within a designation | the designation |

Levels: France **AOC › Vin de Pays › Vin de France**; Italy **DOCG › DOC › IGT › VdT**.
Bourgogne: a **Grand cru** carries its own name with no village (Montrachet); a **Premier cru**
is village + Premier cru.

## 2. Aromas and the Introduction

- **Primary** aromas come with the grape variety, from **terpenes** in the skin.
  **Secondary** come from pressing, fermentation and early maturation (the **vinous** note).
  **Tertiary** come from long maturation: **esterification** with partial oxidation; vinous
  disappears, primary remain.
- Pulp layers: **acids** by the seed, **sugar** in the middle, **tannins and aromas** under the
  skin. Ripening: sugar up, acid down. Key acids: **malic** and **tartaric**; malic becomes
  lactic during maturation.
- **Phylloxera** killed ~90% of Europe's vines in the late 1800s → American rootstocks.
- Serving: sparkling 6–8 °C, young white 8–10, rosé/aromatic white 10–12, bodied red 16–18,
  long-aged tannic red 18–20. Cold hides sweetness and **raises** tannin.

## 3. France: region ↔ grape

| Region | Grapes |
|---|---|
| Bordeaux left bank (Pauillac, Margaux, St-Estèphe) | Cabernet Sauvignon |
| Bordeaux right bank (St-Émilion, Pomerol) | Merlot |
| Sauternes | Sémillon + Sauvignon Blanc (botrytis) |
| Bourgogne | Pinot Noir (Côte de Nuits), Chardonnay (Chablis, Côte de Beaune), Aligoté (Bouzeron) |
| Beaujolais | Gamay |
| Champagne | Chardonnay, Pinot Noir, **Pinot Meunier** |
| Loire | Sauvignon Blanc (Sancerre, Pouilly-Fumé), Chenin Blanc (Vouvray), Cabernet Franc (Chinon), Muscadet |
| Northern Rhône | Syrah (reds only); Viognier (Condrieu) |
| Southern Rhône | Grenache, Syrah, Mourvèdre (GSM); Châteauneuf-du-Pape up to 13 grapes |
| Alsace | Riesling, Gewürztraminer, Pinot Gris, Sylvaner, Muscat |
| Provence / Corse / Sud-Ouest | Mourvèdre (Bandol) · Vermentino, Sciacarello · Tannat (Madiran), Malbec (Cahors) |

## 4. Italy: designation ↔ region

| Region | Designations |
|---|---|
| Piemonte | Barolo, Barbaresco (Nebbiolo) |
| Lombardia | Franciacorta, Sforzato di Valtellina |
| Veneto | Amarone della Valpolicella, Prosecco (Glera), Soave (Garganega) |
| Trentino-Alto Adige | Trento DOC, Teroldego Rotaliano |
| Friuli-Venezia Giulia | Colli Orientali del Friuli, COF Picolit |
| Emilia-Romagna | Lambrusco di Sorbara, Romagna Albana |
| Toscana | Chianti Classico, Brunello di Montalcino, Vino Nobile di Montepulciano, Bolgheri (Sassicaia) |
| Umbria · Lazio | Montefalco Sagrantino · Cesanese del Piglio |
| Abruzzo / Marche | Montepulciano d'Abruzzo Colline Teramane · Conero, Verdicchio |
| Campania | Taurasi (Aglianico), Fiano di Avellino, Greco di Tufo |
| Puglia · Basilicata | Primitivo di Manduria · Aglianico del Vulture |
| Sicilia | Etna, Cerasuolo di Vittoria, Marsala, Passito di Pantelleria |
| Sardegna | Vermentino di Gallura |

> **Exam focus.** *Vino Nobile di Montepulciano* is Tuscan Sangiovese; *Montepulciano
> d'Abruzzo* is the grape of Abruzzo. The name looks the same and the region is different.
